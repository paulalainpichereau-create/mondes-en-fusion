# Mondes en Fusion

Jeu mobile de fusion physique en 7 mondes (Chantier, Cosmos, Océan, Volcan, Forêt, Bonbons, Pôles), 10 niveaux par monde.

- Bocaux de formes variées, vents, obstacles mobiles, bulles spéciales (bombe, éclair, œuf, colle, trésor…)
- Cartes twist avant les niveaux, compagnons, défi du jour
- Un décor à reconstruire par monde avec les étoiles gagnées

Un seul fichier : `index.html` (HTML/Canvas, aucune dépendance). Sauvegarde dans le navigateur.
